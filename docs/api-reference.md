# API Reference

Base URL: `http://localhost:8000`

## Health

### GET `/`

Returns backend health status.

```json
{
  "status": "ok"
}
```

## Planned Endpoints

- `/auth` - authentication and registration.
- `/courses` - course catalog operations.
- `/grades` - student grade operations.
- `/predictions` - grade prediction requests and history.
- `/admin` - administrative operations.
